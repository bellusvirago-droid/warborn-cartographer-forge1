# The March — Unity project

Drawn by the Cartographer of Warborn Blades and filed by the Scribe.

## How to open it

1. Unzip this archive.
2. In Unity Hub choose **Add project from disk** and pick the unzipped folder.
3. Open with Unity 2022.3 LTS or newer. The packages below install themselves on first open.

## What is where

- `Assets/Scripts/March/` — the C# the Cartographer authored.
- `Assets/Scenes/Manifests/` — scene build orders, object by object.
- `Assets/Documentation/DesignBible/` — the design chapters.
- `Assets/Documentation/AssetRolls/` — what to buy, make, or find.
